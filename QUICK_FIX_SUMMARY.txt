⚙️ TECHNICAL FIX:

   Before:
   -------
   video.src = channel.url;
   video.play();
   // ❌ Doesn't work for HLS streams

   After:
   ------
   if (channel.url.includes('.m3u8')) {
       // Use HLS.js for HLS format
       const hls = new Hls({...});
       hls.loadSource(channel.url);
       hls.attachMedia(video);
   } else {
       // Use native video for direct streams
       video.src = channel.url;
   }
   // ✅ Supports both HLS and direct streams
