TO ACCESS LIVE TV:

Desktop/Laptop:
  1. Click the menu dropdown in top-left corner
  2. Select "🔴 LIVE TV" from the list
  3. Browse channels or use filters to find content

Mobile/Tablet:
  1. Tap the red "LIVE TV" button at the bottom
  2. OR open the menu and tap "🔴 LIVE TV"
  3. Browse and select channels to watch

┌────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                               │
└────────────────────────────────────────────────────────────────────────────┘

DATA FLOW:
  
  1. USER ACCESSES LIVE TV
     ↓
  2. CHANNELS LOAD FROM IPTV SOURCES
     ↓
  3. METADATA EXTRACTED (Logo, Category, Country)
     ↓
  4. CHANNELS DISPLAYED IN GRID
     ↓
  5. USER APPLIES FILTERS/SEARCH
     ↓
  6. CHANNELS REFILTER IN REAL-TIME
     ↓
  7. USER CLICKS CHANNEL CARD
     ↓
  8. PLAYER MODAL OPENS
     ↓
  9. VIDEO STREAM BEGINS
     ↓
  10. USER CONTROLS PLAYBACK

CHANNELS NOT LOADING?
  → Check internet connection
  → Try refreshing the page
  → Sources may be temporarily down
  → Try different country filter

STREAM WON'T PLAY?
  → Channel may be offline
  → Some streams are geo-blocked
  → Try VPN if available
  → Try another channel

SLOW PERFORMANCE?
  → Close other browser tabs
  → Use more specific filters
  → Check internet speed
  → Clear browser cache

PLAYER ISSUES?
  → Try different browser
  → Disable browser extensions
  → Check browser console
  → Update browser to latest
